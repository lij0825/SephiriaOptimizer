# Sephiria Optimizer

세피리아 인벤토리의 아티팩트와 석판 배치를 계산해서 정렬해 주는 모드

[![Release](https://img.shields.io/github/v/release/lij0825/SephiriaOptimizer?style=flat-square&color=2ea44f)](https://github.com/lij0825/SephiriaOptimizer/releases/latest)
[![Sephiria](https://img.shields.io/badge/Sephiria-1.0.33-3b82f6?style=flat-square)](https://store.steampowered.com/app/2436940/Sephiria/)
[![Platform](https://img.shields.io/badge/Windows%20%7C%20Steam%20Deck%20%7C%20macOS-6366f1?style=flat-square)](#설치)

인벤토리를 열고 F5를 누르면 지금 가진 아이템으로 만들 수 있는 가장 좋은 배치로 바꿔 줍니다.
직접 옮기고 싶다면 F6 가이드를 켜 두고 칸마다 표시되는 위치를 보고 옮기면 됩니다.

게임에 들어 있는 기본 애드온 로더로 돌아가기 때문에 BepInEx 같은 걸 따로 깔 필요는 없습니다.

## 설치

1. [릴리즈 페이지](https://github.com/lij0825/SephiriaOptimizer/releases/latest)에서 `SephiriaOptimizer_v2.1.0.zip`을 받습니다.
2. 압축을 풉니다. zip 안에서 바로 실행하면 설치가 안 되니 꼭 풀어 주세요.
3. 설치 파일을 실행합니다.
   - Windows: `Install.bat` 더블클릭
   - Steam Deck, Linux, macOS: 터미널에서 `chmod +x install.sh && ./install.sh`
4. 게임을 켜고 인벤토리(I 또는 Tab)를 열면 화면 옆에 패널이 보입니다.

게임 폴더는 설치 파일이 찾아 줍니다. 스팀 라이브러리를 D 드라이브 같은 다른 곳에 둔 경우도 괜찮고, 그래도 못 찾으면 폴더를 고르는 창이 한 번 뜹니다.

지우고 싶을 때는 `Uninstall.bat`을 실행하거나 `./install.sh --uninstall`을 입력하면 됩니다.

## 사용법

패널은 인벤토리를 열었을 때만 나옵니다. 물약 가방이나 인벤토리 칸을 가리지 않는 쪽에 자리를 잡고, 상점이나 제단 창이 왼쪽에 뜨면 오른쪽으로 옮겨 갑니다.
위치가 마음에 안 들면 패널 제목을 잡고 끌어서 옮길 수 있고, `⇄` 버튼으로 왼쪽/오른쪽 고정, `—` 버튼으로 접어 둘 수 있습니다.

| 키 | 하는 일 |
| --- | --- |
| F5 | 자동 정렬. 아이템 위치를 바꾸고 석판도 돌려 줍니다. |
| F6 | 칸 위에 이동 위치, 회전, 예상 레벨을 표시합니다. |
| F7 | 빌드 설정 창을 엽니다. |
| 우클릭 | 아티팩트 우선순위를 바꿉니다. Pin을 켜 둔 상태라면 그 칸을 고정합니다. |

전투 중이거나, 마우스로 아이템을 들고 있거나, 감정·인챈트처럼 인벤토리가 잠긴 상태에서는 F5를 눌러도 아이템을 옮기지 않습니다. 이때는 가이드만 표시됩니다.

### 칸 위에 뜨는 표시

- `→[2,3]` 이 아이템을 2열 3행으로 옮기라는 뜻입니다.
- `↻ +90°` 제자리에서 석판을 그만큼 돌리라는 뜻입니다.
- `Lv.2/4`, `Lv.3 (MAX)` 옮긴 뒤의 예상 레벨입니다.
- `비활성` 빨간색으로 뜨면 그 자리에서는 아티팩트가 꺼진다는 경고입니다.
- `PIN` 고정해 둔 칸입니다.

## 빌드 설정 (F7)

계산이 내 빌드와 다르게 나올 때 여기서 조정하면 됩니다.

- **캘세더니 열쇠**: 줄마다 붙는 속성(견고, 잉걸불, 빙하, 마법공학) 중 원하는 걸 고릅니다.
- **목표 세트**: 맞추고 싶은 세트를 체크하면 그 세트 숫자를 우선해서 채웁니다. 하얀 종이도 이 기준으로 놓입니다.
- **북향의 금빛침**: 금빛침을 붙일 공격 아티팩트를 직접 고를 수 있습니다. 안 고르면 제일 효과가 큰 쪽에 붙입니다.
- **우선순위**: 아티팩트마다 최상 / 높음 / 보통 / 낮음 / 최하로 정할 수 있습니다.
  최상은 석판 버프를 먼저 받고, 최하는 세트 숫자만 채우는 용도라 마이너스 칸을 대신 막는 데 씁니다.

## 업데이트

게임을 켤 때 새 버전이 나왔는지 한 번 확인합니다. 새 버전이 있으면 패널에 `원클릭 업데이트` 버튼이 생기고, 누르면 바로 받아서 교체한 뒤 게임을 다시 켜라고 알려 줍니다.

세피리아가 업데이트돼서 모드가 맞춰진 버전(1.0.33)과 달라지면 패널 위에 알림이 뜹니다. 버전 숫자만 바뀐 거라면 그냥 써도 되고, 게임 내부 구조가 바뀐 경우에는 아이템이 꼬이지 않도록 F5만 잠기고 가이드는 계속 쓸 수 있습니다.

## 계산할 때 고려하는 것들

- 석판의 +/− 레벨, 배율, X(비활성) 효과
- 바닥 각인과 신비 세트. 신비 칸에서는 석판과 각인 수치가 2배가 됩니다.
- 아티팩트 최대 레벨. 넘치는 버프는 다른 아티팩트에 나눠 줍니다.
- 위치 조건이 있는 아티팩트 (맨 위, 맨 아래, 양 끝, 테두리, 안쪽, 양옆 등)
- 북향의 금빛침은 대상 아티팩트 바로 아래 칸에 붙입니다.
- 조화의 수정은 주변 8칸 아티팩트 레벨 합이 높아지도록 둡니다.
- 혼돈의 동료, 행성 모듈, 마법 탄환, 목각 상자, 화염과 냉기 같은 위치 시너지
- 생존 20(석판 각인), 고유한 한 쌍, 무한 콤보 같은 재능

<details>
<summary>권한이 없다고 나와요.</summary>

게임이 `C:\Program Files (x86)` 아래에 있으면 관리자 권한이 필요합니다. 확인 창에서 "예"를 누르거나 `Install.bat`을 우클릭해서 관리자 권한으로 실행해 주세요.

<details>
<summary>F5를 눌러도 아무 일도 안 일어나요.</summary>

<br>

- 이미 가장 좋은 배치라서 옮길 게 없는 경우일 수 있습니다. 패널의 점수가 같으면 이 경우입니다.
- 전투 중이거나 아이템을 들고 있으면 옮기지 않습니다.
- 패널 아래 상태 줄에 오류가 적혀 있다면 그 내용을 이슈로 남겨 주세요.

</details>


## 직접 빌드하기

.NET 8 SDK와 세피리아가 설치되어 있어야 합니다. 게임 폴더는 빌드할 때 자동으로 찾습니다.

```powershell
# 빌드 (Dist 폴더에 zip이 만들어집니다)
dotnet build SephiriaOptimizer.sln -c Release

# 빌드하고 내 게임에 바로 설치
dotnet build SephiriaOptimizer.sln -c Release -p:DeployToGame=true

# 테스트
dotnet test SephiriaOptimizer.sln -c Release
```

새 버전을 올릴 때는 `SephiriaOptimizer.csproj`와 `metadata.json`의 버전을 바꾸고, 빌드한 결과물을 커밋한 다음 태그를 올리면 됩니다.
릴리즈 설명은 `.github/release-notes/v버전.md`에 적어 두면 같이 올라갑니다.

```bash
git tag v2.1.0
git push origin v2.1.0
```

버그나 건의 사항은 [Issues](https://github.com/lij0825/SephiriaOptimizer/issues)에 남겨 주세요.
